## 📖 About the Game

**TRASHFORM** is a 3D environmental awareness game developed using Unity. The main goal of the game is to transform a polluted and damaged city into a clean, green, and beautiful environment.

The game allows players to explore a polluted city, collect rubbish, recycle waste materials, and rebuild damaged objects using recycled resources.

Through these activities, TRASHFORM aims to encourage environmental responsibility and teach players the importance of waste management, recycling, and protecting the environment.

**Our Mission: Clean the City, Recycle Waste, and Rebuild a Better Future!**

## 🌍 Game Story

Once, Green City was a beautiful and peaceful place filled with trees, parks, and clean streets.

Over time, pollution and careless waste disposal damaged the environment. The streets became filled with rubbish, public areas became polluted, and many objects in the city were damaged.

Green City needs a hero to bring back its beauty.

**The player becomes the hero of Green City.**

The player's mission is to explore the city, collect rubbish, recycle waste, and use recycled materials to restore the environment.

Every completed mission brings Green City one step closer to becoming a clean and beautiful place again.

## 🎯 Game Objectives

- Create awareness about environmental pollution.
- Encourage proper waste collection and disposal.
- Teach players how to separate recyclable materials.
- Demonstrate the importance of recycling.
- Promote the reuse of recycled materials.
- Encourage players to protect the environment.
- Provide an enjoyable 3D gaming experience.

## 🎮 Gameplay Overview

TRASHFORM is designed around three main levels.

### 🗑️ Level 1 – CLEAN: Collect Rubbish

**Mission: Clean the Polluted City**

The player explores polluted areas of Green City and collects scattered rubbish.

**Main Tasks:**
- Explore streets, parks, and public areas.
- Find rubbish scattered around the environment.
- Collect waste materials.
- Clean polluted areas.
- Complete the cleaning mission to progress to the next level.

**Goal:** Collect rubbish and prepare the waste for recycling.

### ♻️ Level 2 – RECYCLE: Waste Sorting

**Mission: Turn Waste into Useful Resources**

After collecting rubbish, the player must sort the collected waste into the correct recycling categories.

**Waste Categories:**

| Category | Examples |
|---|---|
| Plastic | Plastic bottles and containers |
| Glass | Glass bottles and jars |
| Organic | Food waste and leaves |
| Metal | Metal cans and objects |

**Main Tasks:**
- Identify different waste materials.
- Select the correct recycling category.
- Sort the collected rubbish.
- Avoid incorrect waste sorting.
- Complete the recycling challenge.

**Challenge:** Incorrect waste sorting costs one life.

**Goal:** Correctly sort the collected waste into recycling categories.

### 🏗️ Level 3 – REBUILD: Restore Green City

**Mission: Rebuild a Better City**

The player uses recycled materials to repair damaged objects and restore Green City.

**Main Tasks:**
- Explore damaged areas of the city.
- Identify objects that need repairs.
- Select suitable recycled materials.
- Repair damaged objects.
- Complete restoration tasks.
- Help transform Green City into a clean and beautiful environment.

**Challenge:** Selecting incorrect materials costs one life.

**Goal:** Restore damaged parts of Green City using recycled resources.

## ❤️ Game Rules

The proposed game rules are:

1. The player starts each new game with **five lives**.
2. Incorrect waste sorting reduces one life.
3. Incorrect material selection during rebuilding reduces one life.
4. Correct choices allow the player to continue the mission.
5. When all five lives are lost, the current level restarts.
6. The player can retry the current level without restarting the entire game.
7. Completing the required tasks allows the player to progress through the game.

*Note: These rules are part of the planned gameplay and have not yet been implemented in the current prototype.*

## 🚀 How to Run the Project

The project is currently under development.

To open the available Unity project:

1. Install Unity Hub and a compatible Unity Editor version.
2. Clone the GitHub repository.
3. Open Unity Hub.
4. Select **Add Project from Disk**.
5. Select the downloaded Unity project folder.
6. Open the project using the appropriate Unity Editor version.
7. Open the main scene from the project's `Assets` folder.
8. Press **Play** to view the available prototype.

**Clone the Repository:**

```bash
git clone https://github.com/tharindu-malshan/Trashform.git
```
